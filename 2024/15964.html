PVE安装openWRT虚拟机并设置旁路网关的尝试
Chenghow
  2024-05-02 17:30:04 2024-05-02 17:30   2024-05-03 00:19:16  
  • 我的学习笔记 
  • | 爱折腾 

软硬件条件

  • 主角：熊猫工控3965U 单千兆网口
  • 网络拓扑：中国移动网-校园网-楼层交换机-AC路由器-小米路由器（提供WIFI）-3965U
  • PVE 版本：8.2.2

获取镜像

  • openWRT官方：https://archive.openwrt.org/

镜像选择

64：具有64位功能的计算机；
generic：一般的，通用的，仅32位计算机，奔腾4及以上，i586 Linux；
legacy：遗留的，停产的，奔腾4之前的，i386 Linux；
geode：为AMD公司的geode处理器定制的；

squashfs：一种只读压缩文件系统，该磁盘映像使用传统布局，包括一个只读分区和一个读写分区，读写分区大小受限，可恢复出厂设置；
ext4：一种linux文件系统，该磁盘映像使用单个读写ext4分区，可以扩大分区，不可恢复出厂设置；
Combined：组合的，包括bootloader、kernel、rootfs
efi：UEFI底层系统，使用GPT分区表。区别于传统的BIOS，使用MBR分区表
bootloader：引导程序
kernel：Linux内核
rootfs：openwrt根系统

我的机器选择generic-ext4-combined-efi.img.gz或者generic-ext4-combined.img.gz

由于解压下来的镜像是img格式，我们需要先创建虚拟机，创建时选择不使用任何介质，再将其写入到硬盘，其他默认。创建时也不需要添加硬盘，因为以下命令会添加。
qm disk import 101 name.img local-lvm

其中的101是你创建的虚拟机的的vmID,name.img是你上传镜像的名字

虚拟系统配置

之后启用创建好的硬盘，启动虚拟机，更改openwrt的网络设置。

vi /etc/config/network

其中按i进入编辑，esc回到命令模式，命令模式下 :wq保存并退出 :q!强制退出

config interface ‘lan’
option device ‘br-lan’
option proto ‘static’
option ipaddr ‘192.168.31.54’
option netmask ‘255.255.255.0’
option ip6assign ‘60’

将ipaddr改为和上游同一网段的ip，这个ip就是你op后台的ip。
进入后台在，网络-接口修改br-lan的网关为上游路由器ip,我这里是小米路由器的ip地址192.168.31.1 ,dns也一样，然后关闭DHCP服务。

设置完成后在网络-网络诊断测试网络，确保系统连上网。

安装对应插件，将其他设备网关设置为openwrt的ip即可。

遇到的问题

openwrt的选择

一开始我选用的是官方的openwrt，换源十分麻烦，LuCI应用列表也不完整，后来用了Immortalwrt，预装中文，ipk源国内可连。

直接加载镜像而没有写入硬盘

Immortalwrt提供了可以引导启动的iso镜像，但openwrt没有写入硬盘的选项，重启后数据丢失

延迟增加

由于多一层路由，网络的延迟怎加，稳定性欠缺

追求网卡直通

将唯一的网卡直通，和原来的设置冲突，导致无法进入pve后台

未来计划

通过转接卡增加PCIE网卡，从旁路由变为主路由。这样一来可以降低延迟提高稳定性。并且在校园网环境下，可以通过openwrt的软件包实现校园网多设备连接防检测。
