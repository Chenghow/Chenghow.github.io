几个概念

以太网 Ethernet

以太网是一种计算机局域网技术。包括物理层的连线、电子信号和介质访问层协议的内容。以太网是现实世界中最普遍的一种计算机网络。

以太 Ether 原本指西方哲学中一种抽象的物质，无处不在。Ether在Linux ifconfig里面多指MAC地址

以太网和OSI中的物理层、数据链路层对应。
家用常见的网线便是水晶头和双绞线的组合
NIC Network Interface Care 网卡

flowchart LR
    以太网 --> 物理层
    以太网 --> 数据链路层
    物理层 --> 线缆
    物理层 --> 设备
    线缆   --> 同轴电缆
    线缆   --> 光纤
    线缆   --> 双绞线
    设备   --> 任何包含NIC的设备
    设备 --> 网关
    设备 --> 网桥
    数据链路层 --> 逻辑链路控制LLA
    数据链路层 --> 介质访问控制MAC

桥接 bridge

将网络的多个网段在数据链路层（OSI模型第2层）连接起来。

物理地址

物理地址，也称为链路地址、MAC地址、LAN地址，它是局域网或广域网定义的节点地址。它包含在数据链路层所用的帧中，是最低级的地址。物理地址在网络(LAN或者WAN)中使用，这类地址的长度和格式是可变的。以太网使用6个字节(48位)物理地址，在网络接口卡(NIC)上标明。这个地址实际上是用于数据链路层，而不是如它名字所指的物理层上的。

子网

子网（英语：Subnetwork）在因特网协议（Internet Protocol，IP）中，子网指的是从分类网络中划分出来的一部分。
如192.0.2.96/28 表示一个使用 CIDR (无类别域间路由) 表示法的 IPv4 子网

网络地址

网络地址 (Network Address) 是一个子网的起始地址，用来标识这个子网。
对于 192.0.2.96/28，网络地址就是 192.0.2.96。
网络地址相同，则处于同一网段

主机地址

可用主机地址 (Host Addresses) 是指可以分配给设备（如计算机、路由器等）的 IP 地址。
确定广播地址：

广播地址是将网络地址的主机部分全部设置为 1 的结果
网络地址：11000000.00000010.00000000.01100000
主机部分：0000
广播地址：11000000.00000010.00000000.01101111，即 192.0.2.111
确定可用主机地址范围：

主机地址范围从网络地址的下一个地址开始，到广播地址的前一个地址结束：
192.0.2.97 到 192.0.2.110
通过以上步骤，我们可以清楚地知道 192.0.2.96/28 表示的子网范围和可用的 IP 地址。

广播地址

广播地址 (Broadcast Address) 是指一个子网中的最后一个 IP 地址，用于向该子网内的所有设备发送数据包。它的作用是在子网内进行广播通信。广播地址是子网中的最后一个 IP 地址，其主机部分全为 1
以太网和IPv4网都用全1的地址表示广播，分别是ff:ff:ff:ff:ff:ff和255.255.255.255。

举个例子，假设你的局域网中有四台计算机，它们的 IP 地址范围是：192.168.0.1 - 192.168.0.4，子网掩码为 255.255.255.0。如果你想向整个局域网发送一个广播消息，你可以将目标地址设置为 192.168.0.255，这是该网络的广播地址。这样，所有四台计算机都能够接收到该消息，并根据需要作出响应。

网络地址-可用主机地址-广播地址

APR

ARP 协议的全称是 Address Resolution Protocol(地址解析协议)，它是一个通过用于实现从 IP 地址到 MAC 地址的映射，即询问目标 IP 对应的 MAC 地址 的一种协议。ARP 协议在 IPv4 中极其重要。

注意：ARP 只用于 IPv4 协议中，IPv6 协议使用的是 Neighbor Discovery Protocol，译为邻居发现协议，它被纳入 ICMPv6 中。

回环网卡 lo

回环网卡（Loopback adaptor），是一种特殊的网络接口，不与任何实际设备连接，而是完全由软件实现。与回环地址（127.0.0.0/8 或 ::1/128）不同，回环网卡对系统“显示”为一块硬件。任何发送到该网卡上的数据都将立刻被同一网卡接收到。例子有 Linux 下的 lo 接口和 Windows 下的 Microsoft Loopback Interface 网卡。

回环（英语：loopback）指将电子信号、数据流等原样送回发送者的行为。它主要用于对通信功能的测试。

路由表 routing table

在局域网中，节点也不知道如何发送IP包到网关。将数据包发到正确的地址是一个复杂的任务，网关需要记录发送数据包的路径信息。路由表就存储着这样的路径信息，就如地图一样，是一个记录路径信息，并为需要这些信息的节点提供服务的数据库。

几个命令

ifconfig命令

Linux ifconfig(short for interface config)命令用于显示或设置网络设备。ifconfig可设置网络设备的状态，或是显示目前的设置。类似于Windows的ipconfig (standing for “Internet Protocol configuration”)命令。

常用命令

ip 命令

Linux ip 命令与 ifconfig 命令类似，但比 ifconfig 命令更加强大，主要功能是用于显示或设置网络设备。
ip 命令是 Linux 加强版的的网络配置工具，用于代替 ifconfig 命令。

路由表解析

  1. 默认路由
  • default: 默认路由，表示如果没有其他更具体的路由规则匹配，则使用这条规则。
  • via 10.0.20.1: 下一跳（网关）IP 地址是 10.0.20.1。
  • dev eth0: 通过网络接口 eth0。
  • proto dhcp: 这条路由是通过 DHCP 协议获得的。
  • src 10.0.20.7: 数据包的源 IP 地址为 10.0.20.7。
  • metric 100: 路由的优先级，数值越低优先级越高，这里的优先级为 100。
  1. 本地子网路由
  • 10.0.20.0/22: 子网 10.0.20.0/22（包括 IP 地址范围 10.0.20.0 到 10.0.23.255）。
  • dev eth0: 通过网络接口 eth0。
  • proto kernel: 这条路由是由内核自动添加的。
  • scope link: 只在直接连接的网络中有效。
  • src 10.0.20.7: 数据包的源 IP 地址为 10.0.20.7。
  • metric 100: 路由的优先级为 100。
  1. 网关的直接路由
  • 10.0.20.1: 指定网关 IP 地址。
  • dev eth0: 通过网络接口 eth0。
  • proto dhcp: 这条路由是通过 DHCP 协议获得的。
  • scope link: 只在直接连接的网络中有效。
  • src 10.0.20.7: 数据包的源 IP 地址为 10.0.20.7。
  • metric 100: 路由的优先级为 100。
  1. Docker 网络
  • 172.17.0.0/16: Docker 默认桥接网络的子网。
  • dev docker0: 通过 Docker 的网络接口 docker0。
  • proto kernel: 这条路由是由内核自动添加的。
  • scope link: 只在直接连接的网络中有效。
  • src 172.17.0.1: 数据包的源 IP 地址为 172.17.0.1。
  1. 特定外部 IP 路由
  • 183.60.82.98: 特定的外部 IP 地址。
  • via 10.0.20.1: 通过网关 10.0.20.1。
  • dev eth0: 通过网络接口 eth0。
  • proto dhcp: 这条路由是通过 DHCP 协议获得的。
  • src 10.0.20.7: 数据包的源 IP 地址为 10.0.20.7。
  • metric 100: 路由的优先级为 100。
  1. 另一个特定外部 IP 路由
  • 183.60.83.19: 另一个特定的外部 IP 地址。
  • via 10.0.20.1: 通过网关 10.0.20.1。
  • dev eth0: 通过网络接口 eth0。
  • proto dhcp: 这条路由是通过 DHCP 协议获得的。
  • src 10.0.20.7: 数据包的源 IP 地址为 10.0.20.7。
  • metric 100: 路由的优先级为 100。
